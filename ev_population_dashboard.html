Deeper analyses you can run as a data analyst

  • GeospatialMap charging infrastructure gaps vs EV density using the vehicle location (GPS) column and public charger APIs — reveal counties underserved relative to demand.
  • ForecastingBuild a time-series model (ARIMA or Prophet) on model-year adoption to forecast 2025–2030 EV fleet size and grid demand load.
  • PricingAnalyze Base MSRP vs Electric Range to find the best value EVs — scatter plot with a value frontier line segmented by make.
  • PolicyCorrelate CAFV eligibility status with legislative district to see if state incentive zones actually drive higher adoption in targeted areas.
  • SegmentationCluster vehicles using Make + Range + MSRP + Type to define consumer segments (budget BEV, luxury BEV, practical PHEV, etc.) — useful for dealership targeting.
  • Churn proxyGroup registration years by county: if older EVs concentrate in one area and newer ones in another, it signals shifting demand or depreciation patterns.
  • Utility impactThe Electric Utility column lets you group demand load by utility provider — critical for grid planning and utility-specific EV rebate programs.
  • Model popularity decayTrack model-year × make combinations to see which models had short peaks (Bolt Gen 1) vs sustained growth (Model Y) — reveals product lifecycle patterns.
